## 🔬 Featured Projects

### 🛡️ [GWAS-SAFE](https://github.com/xiaoh11/GWAS-SAFE)
**Machine Learning · Genomic Privacy · Statistical Genetics**

A machine learning framework for assessing individual re-identification risks from sequencing-based GWAS summary statistics.

- Evaluates privacy risks associated with sharing rare genetic variants.
- Investigates allele-count thresholds to support safer sharing of GWAS results.
- Uses population-scale sequencing data, simulated genetic relationships, and machine learning models.

### 📊 PheWeb2 / PheWeb3
**Full-Stack Development · GWAS · Interactive Visualization**

Interactive web platforms for exploring and visualizing large-scale genome-wide association study results.

- Develops interactive interfaces for phenotype, gene, and genomic region exploration.
- Supports stratified GWAS analysis and visualization across populations and sex groups.
- Integrates modern frontend technologies with scalable backend APIs and genomic data processing pipelines.

**Live platforms:** [CLSA PheWeb2](https://clsa-pheweb.cerc-genomic-medicine.ca/) · [CARTaGENE PheWeb2](https://cartagene-pheweb.cerc-genomic-medicine.ca/) · [UKB Imaging PheWeb2](https://imaging-pheweb.cerc-genomic-medicine.ca/)

### 🧬 [CARTaGENE Bravo](https://cartagene-bravo.cerc-genomic-medicine.ca/)
**Genomic Databases · Full-Stack Development · Variant Annotation**

An interactive genomic variant browser for exploring whole-genome sequencing data.

- Enables interactive variant exploration, filtering, and annotation.
- Supports efficient querying of large-scale genomic datasets.
- Integrates genomic databases with RESTful APIs and web-based visualization.
